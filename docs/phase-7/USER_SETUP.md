# Website builder (Phase 7)

This is optional. It does **not** replace a connected existing website. Ocean Sailing Adventures checkout stays on the sailing site.

The builder works like SiteOrigin: **rows** across the page, **columns** inside a row, **widgets** inside a column.

## After this is on Production

1. Open https://www.groovgro.com/app and sign in.
2. In the left Work list, open **Website builder**.
3. If you do not have a GroovGro page yet, pick a starting layout (they all include a three-column row) and click **Create draft website**.
4. To make one row with three columns on an existing page:
   1. Under **Add a row**, click **Three columns**.
   2. You should see one row with three dashed cells side by side.
   3. In a cell, choose a widget type (for example **Text**) and click **Add widget**.
   4. Repeat for the other two cells.
5. Click a widget to edit its words. The preview updates as you type. Click **Save section**.
6. Drag a widget by the handle into another column if you want it somewhere else.
7. On a row, you can change **Set columns** (one, two, three, four, wide left, wide right, wide center), **Move row up/down**, or **Remove row**.
8. Click **Publish**, then **Open page**. On a computer you should see three columns. On a phone they stack.
9. Confirm https://www.oceansailingadventures.com/ is unchanged.

To switch the whole page, open **Start from a different template**, pick a layout, and click **Use this template**. That replaces the GroovGro page only.

## Apply an approved SEO draft onto this GroovGro page

1. Open **SEO**.
2. Approve a **Page title**, **Meta description**, or **Main heading** draft.
3. In **Earlier decisions**, click **Apply to GroovGro website**.
4. Confirm the GroovGro preview changed and the connected website did not.

**Unpublish** hides the GroovGro page only. It does not change the connected website or Stripe.

Custom domains and image uploads are later slices.

# Website builder (Phase 7, first slice)

This is optional. It does **not** replace a connected existing website. Ocean Sailing Adventures checkout stays on the sailing site.

## After this is on Production

1. Open https://www.groovgro.com/app and sign in.
2. In the left Work list, open **Website builder**.
3. Click **Create draft website**. GroovGro fills starter sections from Brand.
4. Open each section → **Edit copy** → change the words → **Save section**.
5. Use **Move up** / **Move down** / **Remove** / **Add section** as needed.
6. Click **Publish**.
7. Click **Open page** (or copy the `/w/...` link) in a private window. You should see the GroovGro-hosted page.
8. Confirm https://www.oceansailingadventures.com/ is unchanged.

**Unpublish** hides the GroovGro page only. It does not change the connected website or Stripe.

Custom domains for GroovGro-built sites are a later slice. Images, more section types, and applying SEO drafts onto this page also wait.
